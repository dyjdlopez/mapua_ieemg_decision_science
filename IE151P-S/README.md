# IE151P-S — Advanced Computer Applications

Welcome! This folder contains the lecture materials for **IE151P-S: Advanced Computer Applications**. This README explains what the course covers, what you're expected to be able to do by the end of it, and what software you'll need to follow along.

---

## Course Description

This course introduces you to advanced computer applications for data mining. You'll work through realistic business, operations, and management scenarios and apply data processing and analysis tools to support decision-making in industrial and management engineering contexts — using real tools against real problems, not just theory.

**Note on tools:** materials in this repository are built and demonstrated **in Python**, run on Google Colab. Python is the tool you'll use for every hands-on exercise and activity in this course.

---

## Course Objectives

By the end of this course, you should be able to:

1. **Interpret datasets** for different applications and identify which tools/techniques fit a given problem.
2. **Apply data pre-processing techniques** — cleaning, organizing, and preparing data for analysis.
3. **Interpret cleaned data using visualization techniques** to draw conclusions and support real-world decisions.

---

## Course Content

The course is organized into three modules:

### Module 1 — Introduction to Data Mining, Analytics, and Data Pre-processing
- What data mining and analytics are, and why they matter for decision-making
- Data pre-processing techniques and the data value chain
- Data exploration in Python: organization, descriptive statistics
- Correlation analysis
- Distribution analysis

### Module 2 — Data Visualization and Regression
- Data visualization and storytelling (continuous, categorical, and mixed-variable data)
- Regression analysis: theory, metrics, and the properties of linear regression
- Advanced regression: multiple linear regression, Ridge and Lasso regression
- Time-series analysis: autocorrelation, causality, moving averages, autoregressive techniques

### Module 3 — Data Analytics in Real-World Scenarios
- Independent research study applying course concepts to a real dataset/problem
- Culminates in a project paper

## Libraries You'll Need

All notebooks run on **Google Colab**, so most of what you need is already installed — you won't need to set up a local Python environment.

| Library | What it's for |
|---|---|
| `pandas` | Loading, cleaning, and organizing your data |
| `numpy` | Numerical calculations |
| `matplotlib` | Basic plots and charts |
| `seaborn` | Statistical visualizations (distributions, correlation heatmaps) |
| `scikit-learn` (`sklearn`) | Regression models and evaluation metrics |
| `scipy` | Statistical tests |
| `statsmodels` | Regression diagnostics (e.g., checking assumptions like multicollinearity) — may need `!pip install statsmodels` if not already available in your Colab session |

You don't need to install these yourself unless a notebook tells you to — just run the first cell of each notebook, which will handle any missing packages.

## How to Use These Materials

- **Presentations** are provided as PDFs — download them and review before or after each session.
- **Notebooks** (where provided) are meant to be run in Google Colab. Open the file, click "Open in Colab," and run the cells in order from top to bottom.
- If a notebook has a "TODO" or a guided exercise, that's your cue to fill something in yourself — the rest of the notebook is fully worked for you to read and run.
